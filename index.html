ShopFlow

A live multi-vendor store where the last item can only be sold once.

  • Checkout is one database transaction that locks each product row.
  • Vendors can edit only their own products. The API enforces it, not just the UI.
  • JWT login with refresh tokens; the user's role travels in the token.
  • Vendors upload product photos to Cloudinary.

PingBoard

A live uptime monitor that checks your sites every minute and emails you when one goes down.

  • A scheduler calls a secret-protected tick endpoint every minute; each due monitor gets a real HTTP check.
  • Two failures in a row open an incident, so one network blip never sends a false alarm.
  • Alerts go out through Brevo's HTTPS API, because the free host blocks SMTP ports.
  • It is watching ShopFlow and itself right now. That's the status card at the top of this page.
